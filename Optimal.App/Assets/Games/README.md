# Game artwork

These images are used only to identify games in Optimal's local profile library. Game names, logos, key art, and trademarks belong to their respective publishers and are not an endorsement of Optimal.

- Steam titles use the publishers' portrait library artwork served by Steam's `store_item_assets` CDN.
- Fortnite uses Epic Games promotional key art.
- VALORANT uses Riot Games promotional cover art.
- Alan Wake 2 uses Remedy Entertainment promotional key art.

Before distributing a public release, confirm that the intended use complies with each publisher's current brand and media-asset terms.
