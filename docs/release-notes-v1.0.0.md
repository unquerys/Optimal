# Optimal 1.0.0

Optimal 1.0 is the first stable Windows 11 x64 release.

## Highlights

- 74 validated controls organized across tweaks, debloat, gaming, software, maintenance, networking, advanced controls, and repair workflows.
- Hardware-aware onboarding and NVIDIA profile recommendations.
- Simple and advanced catalog modes with search, categories, current-state detection, warnings, sources, dependencies, and conflicts.
- Required fresh restore point before every applied plan.
- Registry backups, operation backups, run journals, progress reporting, restart guidance, and supported reverts.
- Self-contained installer, standalone executable, portable ZIP, and SHA-256 checksums.
- No automatic changes at startup. Every plan remains reviewable and user-confirmed.

## Before installing

The binaries are not currently code-signed, so Windows SmartScreen may display a warning. Download only from this GitHub Release and verify the matching SHA-256 checksum.

Review [TERMS.txt](https://github.com/unquerys/Optimal/blob/main/TERMS.txt) and keep a current backup. Results vary by system and workload.
