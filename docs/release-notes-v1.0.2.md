# Optimal 1.0.2

This is the final first-run and lifecycle repair release.

## Fixed

- Restored the fully branded Optimal installer.
- Fixed installed builds starting without opening the main window.
- Made application shutdown explicit when the main Optimal window closes.
- Cancels active background sampling when the application closes.
- Forces onboarding after the installer launches Optimal for the first time.
- Improved installer terms readability, spacing, contrast, and acceptance controls.

## Safety

Installation does not apply tweaks, remove applications, or run maintenance. Optimal only prepares changes after the user reviews and confirms them in the application.
