# Optimal 1.0.1

This patch repairs the first-run experience reported in 1.0.0.

## Fixed

- Restored the fully branded Optimal installer instead of the partially styled default wizard.
- Fixed the installed application launching without opening its main window.
- The installer now launches Optimal with onboarding after installation.
- Improved terms readability, spacing, contrast, and acceptance controls.

## Safety

Installation does not apply tweaks, remove applications, or run maintenance. Optimal only prepares changes after the user reviews and confirms them in the application.
